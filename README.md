# Claudia De Falco · Letture e scritti

Sito statico (HTML + CSS, nessuna build) con il blog di Claudia De Falco.

- `index.html` – home
- `articoli/psicofagia/` – articolo su *Psicofagia. Immersioni letterarie nel narrare la guerra*
- `assets/psicofagia-de-falco-esposito.pdf` – il progetto completo

## Pubblicazione su Netlify
Add new site → Import from Git → scegli questo repository.
Build command: vuoto · Publish directory: `.` (già impostato in `netlify.toml`).
